Discogs integration

Authorize once. Sync intelligently.

Collexall connects to your Discogs account and keeps the local collection useful on its own. Smart Sync reads collection and Wantlist efficiently and only sends writes that are actually required.

  • Discogs account authorization
  • Bidirectional collection synchronisation
  • Wantlist, folders and per-copy instance tracking
  • Collection value and ratings
  • API request usage shown after sync
  • Remote deletions protected by confirmation

Collexall uses the Discogs API but is not affiliated with, sponsored by, or endorsed by Discogs. Data provided by Discogs remains subject to Discogs terms.

Bulk editing without lock-in

Export. Edit. Import. Update.

Export the collection to CSV, edit locations or other fields in Excel or LibreOffice, then import it again. Stable IDs update the correct copy instead of creating duplicates.

  • Bulk-update shelves and physical locations
  • Preview changes before applying them
  • Safe mode preserves existing values when cells are blank
  • Exact-sync mode when blanks should intentionally clear data
  • JSON backup for complete local recovery
