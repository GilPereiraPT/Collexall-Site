Discogs integration

Identify precisely. Synchronise intelligently.

Collexall connects to a Discogs account while keeping its own local collection database. The integration is designed for exact releases and individual physical copies rather than generic album records.

  • Discogs account authorisation
  • Bidirectional collection synchronisation
  • Exact-release selection after scan or search
  • Folders and per-copy instance tracking
  • Wishlist / Wantlist integration
  • Minimum, median and maximum valuation
  • Ratings and API request usage
  • Remote deletions protected by confirmation

Collexall uses the Discogs API but is not affiliated with, sponsored by, or endorsed by Discogs. Data provided by Discogs remains subject to Discogs terms.

Portable data · no lock-in

Export. Save. Edit. Import. Restore.

The master collection stays on the device, but the data is never trapped there. CSV is designed for spreadsheet editing, JSON for complete backup and restore, and HTML for publishing currently available sale stock.

  • Choose the destination when saving CSV exports
  • Choose the destination when saving JSON backups
  • Clear confirmation after a successful save
  • CSV round-trip for bulk updates
  • Stable IDs update the correct physical copy
  • Preview imported changes before applying them
  • Safe mode can preserve values when imported cells are blank
  • Exact-sync mode can intentionally clear values
  • JSON backup for full local recovery
  • Independent HTML export for available sale items
