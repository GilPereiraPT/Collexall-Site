Everything around the physical copy

More than a barcode scanner.

Collexall covers the full life of a music collection: adding releases, identifying editions, organising shelves, tracking loans, following values, maintaining a Wishlist, preparing items for sale and keeping independent backups.

⌗

Barcode scanning

Use the phone camera to capture EAN and UPC barcodes and search matching music releases quickly.

≡

Batch scanning

Catalogue several items in sequence with a shutter-controlled workflow: one tap, one accepted barcode, then continue through the queue.

▣

Smart Cover Scan

Photograph a cover or choose an image. Text recognition runs locally on the Android device and is used to launch a Discogs search.

⌕

Manual Discogs search

Search by artist, title or release details when a barcode or cover is not enough to identify the exact edition.

◎

Collection statistics

Understand the collection through artists and bands, decades, countries, formats, labels, favourites and other useful breakdowns.

⌁

Search, filters & sorting

Browse the complete collection by text and detailed filters instead of being locked into a single view.

⌂

Physical locations

Store room, furniture, shelf and position so every physical copy can be found again without searching the whole collection.

↔

Loans

Record who borrowed an item, the loan date and expected return date, then close the loan when the copy comes back.

★

Ratings & favourites

Rate releases, mark favourites and keep personal information alongside the Discogs release data.

♡

Discogs Wishlist

Access the Wishlist from Collexall and refresh it when opened so wanted releases remain close to the collection workflow.

Collection value

See cached Discogs minimum, median and maximum estimates and refresh valuation information directly from the app.

Smart Sync

Synchronise intelligently with Discogs while preserving local, per-copy information and avoiding unnecessary API writes.

Discogs integration

Authorize once. Sync intelligently.

Collexall connects to a Discogs account while keeping its own local collection database. Smart Sync reads collection and Wishlist efficiently, tracks Discogs instances and only sends remote changes when they are actually required.

  • Discogs account authorization
  • Bidirectional collection synchronisation
  • Manual release search and exact-edition selection
  • Wishlist, folders and per-copy instance tracking
  • Ratings and collection value information
  • Minimum, median and maximum collection estimates
  • Wishlist refresh when its view is opened
  • API request usage shown after synchronisation
  • Remote deletions protected by confirmation

Collexall uses the Discogs API but is not affiliated with, sponsored by, or endorsed by Discogs. Data provided by Discogs remains subject to Discogs terms.

Turn selected copies into a clean sale catalogue.

Selling is built into the collection workflow rather than being a separate database. Select individual or multiple copies, add commercial details, remove items from sale when needed, preserve sold history and export the currently available stock as a standalone HTML catalogue.

  • Available, sold and all-item views
  • Add to sale or remove from sale individually
  • Select all and clear all selections
  • Asking price and sale notes
  • Media condition and sleeve / cover condition
  • Batch actions for multiple selected items
  • Final sold price and sale date
  • Available inventory total and sales total
  • Custom catalogue title, introduction, contact and currency
  • Responsive HTML with search and format / condition filters
  • Cover images embedded into the HTML whenever available
  • Choose where the HTML file is saved on Android

Portable data · no lock-in

Export. Save. Edit. Import. Restore.

Collexall keeps the master collection on the device, but makes it straightforward to take the data elsewhere. CSV is designed for spreadsheet editing, JSON for complete backup and restore, and HTML for publishing the currently available sale stock.

  • Choose the destination when saving CSV exports
  • Choose the destination when saving JSON backups
  • Clear success confirmation after a file is saved
  • CSV round-trip for bulk updates
  • Stable IDs update the correct copy instead of creating duplicates
  • Preview CSV changes before applying them
  • Safe mode can preserve existing values when imported cells are blank
  • Exact-sync mode can intentionally clear values
  • JSON backup for complete local recovery
  • HTML export uses its own save-file flow and includes available items only
